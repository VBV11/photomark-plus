# Changelog

## 1.1.0

- New Block tool (`B`): a solid rectangle to hide passwords, names or addresses completely.
  It has its own color, black by default, separate from the color of the other tools.
- Setting for the block color.

## 1.0.0

First release.

- Rectangle, ellipse, arrow, numbered marker and pixelate tools.
- "Mark" button on hovered images (tap on touch screens), file and editor context menus, and a command.
- Save by overwriting the original or as a copy, with embed links updated automatically.
- Settings for the button corner and the interface language.
- Works on desktop and mobile. Interface in English and Dutch.
